# DX Mecha photos

Drop one photo per mecha here. The file name must match `image_file` in `data/mecha.csv`
(e.g. `1979_battle-fever-robo.jpg`). Until a file exists, the site shows a typographic placeholder card.

Recommended: square, 1600×1600, black or neutral seamless background, same angle across all photos.
Use your own photos or images you have permission to use.
